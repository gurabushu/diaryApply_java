# つぶやき日記アプリ

JavaおよびSpring Bootの学習成果として作成したWebアプリケーションです。

MVCアーキテクチャを用いたWebアプリケーション開発の基礎を学びながら、CRUD（作成・参照・更新・削除）機能を実装しました。

## 開発目的

- Javaのオブジェクト指向を理解する
- Spring BootによるWebアプリケーション開発を学ぶ
- MVCモデルの仕組みを理解する
- データベースとの連携（CRUD処理）を習得する
- Git・GitHubを利用したバージョン管理に慣れる

## 使用技術

- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- PostgreSQL
- Gradle
- HTML
- CSS
- Git / GitHub

## 実装機能

- トップページ
- お問い合わせページ
- 日記一覧表示
- 日記新規作成
- 日記編集
- 日記削除
- バリデーション
- データベース連携

## 学習内容

本アプリでは、以下の内容を重点的に学習しました。

- MVCアーキテクチャ
- Controller・Service・Entityの役割
- Formクラスを利用した入力値の受け渡し
- Thymeleafによる画面表示
- JPAを利用したデータベース操作
- バリデーション
- Gitを利用したソースコード管理
